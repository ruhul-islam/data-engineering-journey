# Data Engineering Journey

I'm a Technical Analyst working daily with Snowflake SQL, data validation, and business reporting. This repository documents my transition into data engineering: what I'm learning, what I'm building, and the decisions behind it.

## Goal

Build the skills to design, build, and maintain reliable, well tested data pipelines, applying my experience with Snowflake, data validation, and business stakeholders to data engineering work.

## Current Plan (October to December 2026)

* **Weeks 1 to 3:** Containerized data ingestion with Docker, Postgres, and Python
* **Weeks 4 to 5:** dbt and dimensional modeling
* **Weeks 6 to 7:** Workflow orchestration with Airflow
* **Weeks 8 to 10:** End to end logistics data pipeline (Python, AWS S3, Snowflake, dbt, Airflow, GitHub Actions)
* **Weeks 11 to 12:** Testing, documentation, and next steps into Spark and streaming

## Tools and Skills

**Already using:** SQL, Snowflake, Python (pandas), Git, Power BI, Sigma
**Learning:** Docker, Postgres, dbt, Airflow, AWS, Terraform, Spark
